## Mission (W2)

Close the feedback loop: read back performance for posts this app published — Facebook Graph post and page
insights (impressions, reactions, clicks) via the stored Page token — joined to a local publish log (story
slug, banner format, category, publish time), plus the existing `useAiUsage` cost data, rendered in
Activity-desk-style hand-written SVG charts with CSV export. Honest unconfigured state when there is no Page
token. Metrics cached locally with fetch timestamps. A weekly summary table per story (format, category, time,
impressions, reactions). **Never a fabricated or sample number presented as live.**

## Build (W2)

1. `src/editorial/insights.ts`:
   - Publish log: `esb-banner-studio/publish-log/v1` in localStorage (array, newest first, cap 400). Append from
     `PublishDialog.tsx` at the end of a successful publish and dispatch the D9 `esb:story-published` event with
     the same record (one line each; nothing else in that file).
   - Graph: `fetchPostInsights(cfg, postId)` → GET `/{postId}/insights?metric=post_impressions,post_impressions_unique,post_engaged_users,post_clicks,post_reactions_by_type_total`
     and `fetchPageInsights(cfg)` → GET `/{pageId}/insights?metric=page_impressions,page_post_engagements&period=day&date_preset=last_28d`;
     map to a typed `PostMetrics`/`PageMetrics`; map errors: 190 → `expired-token`, 4/17/32 → `rate-limited`,
     100 → `bad-request`, network → `offline`; never retry a 190; back off rate limits (no retry storm: one
     attempt per post per 15 min). The token never appears in a URL, log line, error string or test output.
   - Cache: `esb-banner-studio/insights-cache/v1` keyed by postId with `fetchedAt`; a refresh older than 15
     minutes may refetch, otherwise serve the cache and show its age.
   - `weeklyTable(log, cache, weekStart)` → rows per story; `toCsv(rows)` with `safeCsvCell`.
   - AI summary: `summaryPrompt(rows)` passes only the aggregate table (no article text, no token) inside the
     delimiter pattern; `writeWeeklySummary()` uses the `review` role via `aiJson`; opt-in button only when
     `aiFor('review')` returns a provider and AI is not paused.
2. `src/editorial/InsightsDesk.tsx`: a full-body view toggled by a header `Seg` **Desk · Insights** in
   `EditorialWorkspace.tsx` (mirror Outreach's Compose · Activity). Toolbar: range `Seg` (7 d · 28 d · 90 d),
   Refresh (disabled while rate-limited, shows cache age), Export CSV. Body: unconfigured card when no Page
   token (link to the Facebook dialog), KPI tiles (published, impressions, reactions, clicks, AI cost),
   impressions-by-story `BarChart`, the weekly table, and the AI usage block (`usageTotals`). Empty log →
   "Nothing published from this app yet" (never sample data).
3. CSS additions under `/* W2 — insights desk */` in `src/editorial/editorial.css`, tokens only.
