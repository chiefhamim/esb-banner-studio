## Mission

Persist what `src/editorial/facts.ts` already extracts — quoted spans with speakers, normalized figures with
units — into a searchable library that survives across stories, with a speaker registry, and one-click reuse
as a Quote or Stats banner (both card types exist in `src/core/templates.ts` / `types.ts`: `cardType:
'quote' | 'stat'` with `quoteText`, `speakerName`, `speakerTitle`, `statNumber`, `statLabel`, `statDelta`,
`statNote` on `Content`). Nothing is invented: every entry carries where it came from.

## Build

1. `src/editorial/quoteLibrary.ts` — pure logic + storage:
   - `harvestStory(input)` → entries from the active story: quotes (text, speaker name/title if the sentence
     names one, else unknown), stats (figure as written, normalized value + unit, the sentence). Each entry:
     `{ id, kind: 'quote'|'stat', text, speaker?, value?, unit?, sentence, storyId, slug?, url?, headline,
     categoryId, harvestedAt }`. Deterministic ids from (storyId, kind, normalized text) so re-harvesting the
     same story never duplicates.
   - Dedupe across stories by normalized text (quotes) / (value, unit, sentence) for stats.
   - Persistence with `idbGet/idbSet/idbDel`: one index key `esb-banner-studio/library/index/v1` (ids +
     minimal fields for search) and one key per entry `esb-banner-studio/library/entry/<id>/v1`. Cap:
     `MAX_ENTRIES = 500`, oldest `harvestedAt` evicted first. A write that fails (quota) must not corrupt the
     index: write the entry first, the index last, and verify on read.
   - Speaker registry: `esb-banner-studio/library/speakers/v1` seeded from the orgs in `TAGS` (name, title '',
     org), editable name/title/org; a quote's speaker links to a registry id when the names match.
   - `search(query, { speaker?, org?, kind? })` over text / speaker / org, case-insensitive, Bengali digits
     normalized via the existing helpers.
   - Zustand store `useQuoteLibrary` (load once, in-memory mirror, actions: harvestActive, remove, editSpeaker).
2. Library panel (`src/editorial/QuoteLibraryPanel.tsx`): a `Library` tab in the Editorial left column.
   Search field (32 px, the `or-search` look), filter `Seg` All · Quotes · Stats, a speaker/org `Select`,
   quiet rows like `StoryQueueList` (text, speaker/figure, provenance line "from <headline> · <slug or url>"),
   row actions **Use as quote banner** / **Use as stat banner** (`btn sm`), remove. Empty state: "Nothing
   harvested yet — Harvest from this story" with the button. "Harvest from this story" at the top (on demand).
   Speaker registry editor as a `Panel` at the foot (name/title/org inputs, add, remove).
3. Hand-off: "Use as quote banner" → `useStore.getState().setContent({ cardType: 'quote', quoteText, speakerName,
   speakerTitle })`, then `useShellStore.getState().setWorkspace('graphics')` (same pattern as the headline
   hand-off); "Use as stat banner" → `cardType: 'stat', statNumber: <figure as written>, statLabel: <best
   label from the sentence>, statNote: 'Source: <headline>'`. The quote text is verbatim.
4. Harvest on publish: listen for `esb:story-published` (D9) and harvest the active story; also harvest on
   demand. Record `url`/`slug` from the event when present.
5. CSS under a `/* W1 — quote library */` banner in `src/editorial/editorial.css`, tokens only.
