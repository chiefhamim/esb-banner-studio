## Mission

Bridge Editorial and Outreach: assemble a "This week at ESB PowerLine" digest from the stories this app
published (headline, deck, link, picture when the site has one) and hand it to the existing Outreach campaign
flow as an ordinary **draft** campaign — every existing safeguard (approval, checks, autopilot pacing, dry-run)
applies untouched. The editor picks the date range and stories, reorders, edits the intro. Never an auto-send.

## Build

1. `src/editorial/digest.ts` (pure): `storiesInRange(log, queue, { from, to })` — published stories whose
   `publishedAt` falls in the range (publish log first; a queue item with status `published` but no log row is
   included by `updatedAt` and flagged `source: 'queue'`), newest first, deduped by slug; `assembleDigest(items,
   { intro, title, lang })` → `{ subject, body }` where `body` is letter markup: intro paragraph, then per story
   `## <headline>`, deck line, `[Read the story](<url>)`; a picture line only when a public image URL is known
   (`![…](url)` only if the mark set supports images — otherwise omit, never invent); `emptyWeek(range)` message.
   Escaping: headlines/decks are data — go through the same escaping the composer applies (never raw HTML).
2. `src/outreach/DigestDialog.tsx`: opened from the Campaigns **New** menu item "Campaign from this week's
   stories". Range `Seg` (This week · Last 7 days · Last 30 days) + custom from/to (`DatePicker`), story list
   with checkboxes (`Switch` or the list's own tick pattern), up/down `IconButton`s to reorder, intro `textarea`,
   live preview through the existing email preview iframe, footer **Create draft campaign** (`btn primary`,
   disabled when nothing is ticked) → `createCampaign({ name: 'This week at ESB PowerLine — <range>', kind: 'list',
   blueprint: 'blank', lang: 'en', subject, body, letterhead: true, scheduledAt: null })`. The result is a normal
   draft the editor then gives a list and reviews; nothing else changes in the send path.
3. CSS under `/* W4 — digest */` in `src/styles/outreach.css`, tokens only.
